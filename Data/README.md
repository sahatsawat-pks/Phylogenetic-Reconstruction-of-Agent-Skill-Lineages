# Data Directory: Preprocessed Schemas & Embedding Vectors

This directory contains the preprocessed skill metadata, Sentence-BERT embedding vectors, and raw database descriptions.

---

## 1. Files in this Directory

| Filename | Format | Size | Description |
| :--- | :--- | :--- | :--- |
| `skill_metadata.csv` | CSV | 4.4 MB | Extracted metadata for 29,786 valid skills (13,000 distinct contents). |
| `description_embeddings.npy` | NumPy Binary | 17.5 MB | 384-dimensional dense vectors generated by `all-MiniLM-L6-v2` for skill YAML descriptions. |
| `content_embeddings.npy` | NumPy Binary | 17.5 MB | 384-dimensional dense vectors generated by `all-MiniLM-L6-v2` for skill Markdown body prose. |

---

## 2. CSV Schema: `skill_metadata.csv`

| Column Name | Type | Description |
| :--- | :--- | :--- |
| `artifact_id` | Integer | Unique identifier assigned to each skill occurrence in the dataset. |
| `file_sha` | String (SHA-256) | Hash of the full `SKILL.md` content used for byte-level deduplication. |
| `repo_full_name` | String | Public GitHub repository identifier (`owner/repo`). |
| `skill_name` | String | Name attribute parsed from the YAML front matter. |
| `description` | String | Natural-language description parsed from the YAML front matter. |
| `body_chars` | Integer | Character length of the Markdown body prose (excluding YAML). |
| `code_chars` | Integer | Character count of executable code blocks enclosed in Markdown backticks. |
| `location_class` | String | Directory category in repository (`root`, `.agentskills`, `.cursor/rules`, etc.). |
| `commit_timestamp` | ISO-8601 String | Earliest Git commit timestamp recorded for this artifact version. |
| `author_name` | String | Anonymized Git author name associated with the committing commit. |

---

## 3. Raw SQLite Database Access

The raw GitSkills sample database (`agent_skills_sample.db`, 290 MB) can be unpacked from `agent_skills_sample.zip` located in the parent dataset repository or downloaded via Zenodo. The precomputed embeddings and metadata in this folder allow reproduction of all Research Questions (RQ1–RQ4) without needing to re-embed the entire corpus.
